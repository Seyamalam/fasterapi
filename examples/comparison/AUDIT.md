## Reading the numbers

- Both apps run on **the same uvicorn host** with the same shared stack (async SQLAlchemy + aiosqlite, PyJWT, orjson, pydantic v2), so latency deltas isolate framework overhead (routing, validation, DI solving, response building).
- DB endpoints are dominated by SQLite/SQLAlchemy work common to both; `/ping` isolates pure request plumbing; `/items/expensive` is handler-CPU-bound.
- Loopback RPS swings ±15% run-to-run; treat sub-x1.05 gaps as noise. The differential phase is deterministic and is the hard gate.
- fasterapi's next perf lever (per its README) is the Hyper inverted host (`FASTERAPI_HYPER=1`), which this audit can pick up once promoted.
